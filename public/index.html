Fire Hydrant Hydraulic Flow Chart

Visualize how hydrant discharge pressure responds to changing flows using the Hazen-Williams relation (flow log base 1.85).

Input parameters

Friction loss is computed with the Hazen-Williams relationship: hf = 4.52 · (Q1.85) / (C1.85 · d4.87) (psi per 100 ft). The exponent 1.85 sets the flow log base used for the curve. Residual pressures are capped at zero for readability.
